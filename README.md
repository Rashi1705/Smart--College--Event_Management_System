🎓 Smart College Event Management System

Short description:

- A web-based platform to simplify college event planning, boost student engagement, and streamline communication between clubs, students, and administrators.

Key features :
- **Browse Events:** View upcoming events with details and filters.
- **RSVP / Notifications:** One-click RSVP and reminder notifications.
- **Attendance:** QR or manual attendance marking.
- **Rewards & Leaderboard:** Earn participation points and view rankings.
- **Club Management:** Create, publish, and edit events; manage RSVPs.
- **Admin Controls:** Approve clubs/events, manage users, and view analytics.

Features by role:

- **Student:** Browse events, RSVP, receive reminders, earn points, view leaderboard.
- **Club / Organizer:** Create/publish events, manage RSVPs, mark attendance, update event details.
- **Admin:** Approve clubs/events, manage users, monitor participation analytics and reports.

Modules included:
- **Authentication:** Student registration & login.
- **Club Dashboard:** Organizer tools and event management.
- **Event System:** Creation, publishing, and RSVP flows.
- **Notifications:** Email/notification system for RSVPs and reminders.
- **Attendance Tracking:** QR/manual attendance recording.
- **Rewards:** Leaderboard and points system for participation.

Quick start (local):
- Clone the repo: `git clone <repo-url>`
- Open `index.html` in a browser or serve with a simple HTTP server.
